## 3. Top Architectural & Functional Gaps

1. **Weather Integration Authentication & Endpoint Alignment**:
   - `backend/routes/weather.js` expects OpenWeatherMap (`WEATHER_API_KEY`). If the key is omitted, it falls back to zero severity. To ensure 100% live weather without mandatory paid keys, integrating the free Open-Meteo API (which requires no API keys) as a secondary live upstream source is recommended.
2. **Predictive Intelligence Grounding**:
   - Currently, disruption "prediction" is a deterministic formula (`baseWeight * weatherMultiplier * disruptionMultiplier`). It must be clearly presented to jury members as a **Risk-Weighted Intelligence Engine** rather than an oversold deep learning model.
3. **Storage of Incident Photos**:
   - Currently, photos are base64 encoded and stored directly in database text fields. While functional for a hackathon demo, uploading to Supabase Storage bucket (`incident-photos`) improves query performance.
4. **Security Hardening for Production**:
   - Adding `helmet`, `express-rate-limit`, and strict CORS whitelist ensures readiness for public deployment.
